# automatic-vegetable-billing-system
AI-based automated vegetable billing system using Raspberry Pi, load cell sensors, and computer vision techniques.
Automatic Vegetable Billing System using Raspberry Pi

Overview

This project is an AI-based automated vegetable billing system developed using Raspberry Pi, load cell sensors, HX711 amplifier module, and computer vision techniques. The system automatically identifies vegetables and calculates billing based on real-time weight measurements.

Features

- Automatic vegetable identification
- Real-time weight measurement
- Automated bill generation
- CNN-based vegetable classification
- Embedded system integration
- Computer vision implementation

Hardware Components

- Raspberry Pi 4B+
- USB Camera
- HX711 Amplifier Module
- Load Cell
- Acrylic Weighing Platform

Software & Technologies

- Python
- OpenCV
- Machine Learning
- Embedded Systems
- Raspberry Pi OS

Working Principle

1. Weight detection is performed using a load cell and HX711 module.
2. Once weight is detected, the camera captures the vegetable image.
3. Image preprocessing and classification are performed using CNN techniques.
4. The system calculates the billing amount based on vegetable type and weight.
5. Output is displayed automatically.
